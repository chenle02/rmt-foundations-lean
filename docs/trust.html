Trust and reproducibility

What the verification checks, and what it does not.

Axioms

Every declaration depends only on propext, Classical.choice and Quot.sound. The source contains no sorry, admit, custom axiom or native_decide. The expected axiom output of every audited declaration is recorded in EXPECTED-AXIOMS.txt.

Verification

lake exe cache get
bash scripts/verify.sh

The script requires Python 3 and the pinned toolchain, and starts from a clean project build. It:

  1. checks the source policy (no forbidden tokens or unexpected hypotheses);
  2. builds every production module and test;
  3. compiles every example;
  4. compares the #print axioms output with EXPECTED-AXIOMS.txt;
  5. replays each compiled module through the toolchain's leanchecker.

Full verification ran as Slurm jobs on the Auburn University Easley Cluster.

Limits

A build checks elaboration, the axiom audit checks dependencies, and kernel replay rechecks the compiled declarations. None of them removes a hypothesis, identifies a model limit without its convergence assumption, or establishes the items listed under not established. No independent comparator check is distributed with this release.

The library formalizes known results; it does not claim mathematical novelty.

AI disclosure

Development used OpenAI Codex (gpt-6.1-sol) workers, with Anthropic Claude for orchestration and independent audits. Every result is kernel-checked and depends only on propext, Classical.choice and Quot.sound. Hypotheses and limitations are stated explicitly in the theorem statements.
