Getting started

Build the library from source in four commands.

  1. Install elan. It reads lean-toolchain and installs Lean v4.35.0-rc2, a release candidate. A stable Lean release is not a substitute.
  2. Clone and build:
git clone https://github.com/chenle02/rmt-foundations-lean.git
cd rmt-foundations-lean
lake exe cache get
lake build

lake exe cache get downloads compiled Mathlib, which is pinned in lake-manifest.json. Without it, Mathlib is built from source.

First steps

  • Read examples/Quickstart.lean, a small consumer that imports the library and checks several statements.
  • Use the module map to choose a narrower import than import RMTFoundations.
  • Use the declaration index to find a statement, and the status page for what is and is not proved.

Full verification

bash scripts/verify.sh

This runs the source-policy check, all builds, tests and examples, the axiom audit and kernel replay. See trust and reproducibility for what each step checks.

To depend on the library from another project, see using as a dependency.
