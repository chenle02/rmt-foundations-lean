Using as a dependency

Add the library to a Lake project at the version tag v0.2.0.

Your project must use the same lean-toolchain: leanprover/lean4:v4.35.0. Add to lakefile.toml:

[[require]]
name = "RMTFoundations"
git = "https://github.com/chenle02/rmt-foundations-lean.git"
rev = "v0.2.0"

Then run:

lake update RMTFoundations
lake exe cache get
lake build

Commit your lake-manifest.json; it records the exact revisions that were resolved.

Imports

import RMTFoundations imports everything. For faster builds, import individual modules from the module map, for example import RMTFoundations.TracyWidom.Regularity.

Versions

v0.2.0 is the version tag once released. For an unreleased checkout, pin its exact source commit. For reproducible work, also record the source commit it resolves to and your manifest. The package name in Lake is RMTFoundations; the project name is rmt-foundations.
