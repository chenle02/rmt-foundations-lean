Details and the declarations involved

Rules

Use only the standard axioms. Do not add sorry, admit, custom axioms or native_decide. Preserve statements, attribution and dependency pins, and state hypotheses explicitly. A new structure needs a nondegenerate inhabitation example. See the contribution rules for the validation commands.
